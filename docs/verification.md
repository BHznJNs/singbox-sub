## VPS 验收清单

以下是待在实际部署环境执行的清单，不表示已经完成：

- [ ] 镜像构建或拉取成功，仅提供 `SERVER_ADDR` 并正确映射端口即可启动。
- [ ] 从日志获取订阅 URL，可下载配置并导入 Clash Verge Rev。
- [ ] 选择代理节点后，能够完成实际公网代理访问。
- [ ] 同一容器重启后，身份、令牌和订阅 URL 不变。
- [ ] 使用相同命名卷重建后，身份和令牌不变。
- [ ] 不挂卷删除重建后，生成新身份和令牌。
- [ ] 错误令牌、私钥及状态文件路径均无法取得订阅或内部文件。
- [ ] 参数错误、端口占用及损坏身份导致明确失败退出，无成功启动信息。
- [ ] 正常停止会结束内部服务；任一内部服务意外退出会使容器失败退出。
